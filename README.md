#  Quick Note App

A simple full-stack note-taking application built with HTML, CSS, JavaScript, Node.js, and Express.js.

Users can create, view, search, edit, and delete notes through a clean web interface connected to a live REST API.

##  Features

-  Create notes
-  View all notes
-  Search notes by title or content
-  Edit existing notes
-  Delete notes
-  Refresh notes
-  Success messages
-  Error handling
-  REST API
-  Responsive web interface
- 🚀] Deployed backend
